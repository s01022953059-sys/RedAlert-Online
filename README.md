# RedAlert Online — 铁幕前线

浏览器单人即时战略原型，使用原创 Canvas 图形，不包含原版红警素材。
当前并非原版移植，也未实现或验证 99.99% 仿真。经济、战斗和生产参数为原型设计值，未使用 REA 验证的原版机制。

## 运行

需要 Node.js 18+（测试和构建）及 Python 3（本地服务器），无 npm 依赖。

```sh
npm test
npm run build
npm run dev
```

在运行服务器的电脑浏览器打开 http://localhost:8080 。纯静态部署目录为 `dist/`。
Windows 上也可运行 `py -m http.server 8080 --directory dist`；此命令仅用于预览，不会配置域名、TLS 或系统服务。

## 一局游戏

点击开始，矿车自动开采并在精炼厂交付资金。建议先建发电厂、兵营，再建战车工厂。
建筑完成后点击“部署”并在己方建筑附近的空地左键放置。生产队列最多 8 项，建筑等待部署会阻塞后续生产；被摧毁的生产设施需要重建才能继续单位生产。

左键选择单位，拖动框选；右键地面移动，右键敌军攻击。点击战场后空格暂停；Esc 退出放置模式，右键也可取消放置。矿车完成移动命令后恢复自动采矿。摧毁敌方建造基地获胜，己方基地被毁失败。

## 已实现

- 一张 40×28 地图、玩家与电脑两个阵营、基地与四种可建建筑。
- 有限矿石、自动采矿回款、资金扣费、队列、电力减速。
- 步兵、坦克、矿车；网格 BFS 绕建筑及石块寻路。
- 电脑建设、生产、定期攻击；射程、冷却、生命值及胜负锁定。
- 暂停、重新开局、响应式布局（交互主要面向桌面鼠标）。

## 验证

`npm test`：采矿回款、建筑部署、生产约束、设施摧毁暂停、低电力、寻路、胜负和电脑完整战局。
`scripts/browser-check.py`：使用 Python Playwright 和 `/usr/bin/chromium`，要求预先在 8080 提供 dist；验证实际点击建造/部署、生产、暂停、窄屏溢出及 JS 异常。
